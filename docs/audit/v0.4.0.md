Date: 2026-11-06. Scope: UI-first product surface, native live/resize,
accessibility tree, compact raw storage, CLI simplification, packaging, and
release tooling. The profiler remains read-only.

## Not run here (external/VM)

- `qa/live_smoke.sh`, `qa/service_smoke.sh`,
  `qa/retention_bench.sh 600000 0 2G yes`: require root, perf/tracefs, and a
  disposable Linux VM. The rewritten gates decode compact segments and enforce
  the covered span, bytes/event, and loss thresholds.
- Xvfb/macOS hidden smokes: this host has no `xvfb-run` and is not Darwin; the
  scripts are syntax-checked and wired.
- A human VoiceOver pass and real Developer ID notarization/Gatekeeper/tap
  publication: require macOS, Apple credentials, and a tap token. The tooling
  fails closed and never labels an ad-hoc app as notarized.

## Residual limits

- Linux AT-SPI2 is DEGRADED/JSON-only. The tree, keyboard focus, web ARIA, and
  macOS bridge are implemented.
- Retina 2x crispness, X11 IME/paste parity, and web recorder control are
  follow-ups; the UI shows explicit reasons.
- A/B compare and lab scenarios remain headless automation tools; the console
  does not expose them as controls yet.
- The ten-minute raw claim is workload/budget dependent. The UI/verify report
  the actual covered span and never zero-fill.
- The BPF lane remains a VM-marker-gated no-op load/attach gate.
