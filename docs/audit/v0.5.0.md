# xsprof 0.5.0 audit — native-only console

Date: 2026-11-06. Base: committed 0.4.0 UI-first console. 0.5.0 removes the
shipped browser surface, adds AppImage packaging and native showcase media, and
runs the root-only acceptance gates in a disposable KVM podman VM.

## Removed

- xsprof serve and the loopback HTTP/SSE bridge (/api/*).
- wasm32/WebGL2 frontend, web/ assets, browser QA/Playwright scripts, web
  packaging installs, and the ui-session schema.
- WebGL2/wasm support in the standalone xsui package; CPU/Metal/GL remain.
- xsprof demo no longer has a browser fallback; it opens the native console and
  fails headless with a native-only reason. xsprof serve fails closed as a
  removed 0.5.0 verb.

Kept: the frozen design/index.html prototype as non-runtime design input, the
native CPU/Metal/GL renderers, and the headless lab.

## VM acceptance (real KVM podman machine)

Fedora CoreOS, kernel 7.2.7-200.fc44, 4 vCPU/4 GiB, /dev/kvm, committed 0.4.0
binary sha256 cc438d08... (core recorder unchanged by the web removal).
Evidence: docs/evidence/v0.5.0-vm/.

- live_smoke: PASS. 93,534 recorded rows in 1 s, sched/page-fault events,
  compact daemon + history, capture/verify, SIGTERM clean, bpf-gate READY.
- service_smoke: PASS. 3 compact segments, 421,068 extracted lines, lock
  refusal, SIGKILL recovery marker, canonical extraction, watch output.
- retention_bench 600000 0 2G yes: PASS. 51,912,224 retained events at
  86,517/s, 12.06 compact bytes/event, 625,946,419 bytes, covered 600.01 s,
  zero retained loss, 10 sidecars, 12,928 KiB RSS, 6,148 bp overhead.
  Same-VM canonical samples are 160.10 bytes/event, ratio 13.28x. The
  10-minute age cap bound before the 2 GiB byte budget.
- doctor inside the VM: kernel/perf/tracefs/pressure/cgroup/libbpf READY,
  host_mutation=false.

## AppImage

tools/package_appimage.sh produced dist/Xsprof-0.5.0-x86_64.AppImage (5.2 MB)
and a SHA256 sidecar. qa/appimage_smoke.sh PASS: version 0.5.0, help, CPU
snapshot, no web assets, no bundled X11/GL/driver libraries, and it runs through
--appimage-extract-and-run without FUSE. The AppImage is unsigned/not notarized
and uses the host GPU driver stack.

## Native showcase media

Deterministic offscreen native renders (no real window, no x11grab):
design/media/xsprof-native-showcase.mp4/.gif and
xsprof-native-live-replay.mp4/.gif with canonical provenance. The live replay
uses a bounded excerpt of the committed real VM capture, labelled REPLAY.
qa/showcase_smoke.sh PASS verifies provenance, frame determinism, and absence of
display capture.

## Post-release fixes

- `471b2ca`: Recorder probe SKIP/REFUSE rendered honestly with the capture
  requirement; in-app export/verify actions; permission guide.
- `5fd611c`: Live feed stop stall. When the 8 MiB bounded feed filled, trimming
  copied the whole feed per appended event, so stop blocked joining the tail.
  Fixed with coarse half-buffer trim and a thread-safe live allocator. See
  [live-feed-stall.md](live-feed-stall.md).

## Known limits

- Linux AT-SPI2 screen-reader bridging remains DEGRADED/JSON-only.
- macOS VoiceOver and real-window resize require a human-run macOS pass.
- The native showcase media is an offscreen render, not a real-window screen
  recording. True live-window video requires a human-run recording.
- AppImage relies on host X11/GL; it is not notarized.
- A/B compare and lab scenarios remain headless automation tools.
- Real Developer ID notarization and tap publication remain external-credential
  gated; the pipeline is fail-closed and locally tested.
